# learning-ta-support

GitHub Pages site for the old support and privacy addresses of Learning TA (on the stores as
"Technical Analysis Course") by Crow Tech Pte. Ltd.

The support and privacy pages now live on crow.sg:

- https://crow.sg/apps/learning-ta/support/
- https://crow.sg/apps/learning-ta/privacy/

This site keeps the old addresses working: `/`, `/support/` and `/privacy/` send the browser on
to crow.sg.
